## Methodology and limits

- Detection of "read in code" = substring search for the env key in .ts/.mjs/.js/.cjs files.
- This catches both `process.env.KEY` and indirect reads via `process.env[name]`,
  but **misses** computed names like `process.env[`KEY_${SUFFIX}`]`. Such cases are extremely rare.
- Files in `data/`, `archive/`, `node_modules/`, `.git/` excluded.
- `.sh` wrappers in `scripts/` only **export** env, they are not "readers".
- Raw JSON: `_env-inventory-raw.json` (in this folder).
